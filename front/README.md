# Visora 前端

Visora 统一访问统计平台的管理界面，基于 shadcn-admin、React、TypeScript、TanStack Router / Query 与 shadcn/ui。

请在上一级项目根目录按 [Visora 使用说明](../README.md) 安装、启动和部署。开发界面默认运行在 `http://127.0.0.1:5173`，需要同时运行后端。

页面包含访问概览、访问明细、项目管理、接入指南和管理员登录。原始模板组件保留供复用，产品路由仅开放 Visora 页面。

原模板：<https://github.com/satnaing/shadcn-admin>。保留原 [MIT 许可](LICENSE)。
